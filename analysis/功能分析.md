# LigPrint 功能分析

> 分析方法：完整源码仓库采用逐文件通读；发行产物采用 REA（Reverse Engineering Assistant）只读静态核验交叉验证。
> 结论区分三类：**[源码确认]** 直接来自实现代码、**[产物确认]** 来自 REA 对 EXE 的静态检查、**[推断/未验证]** 无直接证据或需要实机确认。
> REA 静态检查不加载程序集、不执行目标代码；本文不声称动态运行观测。

---

## 一、软件定位

**LigPrint 是一款纯本地的 Windows x64 标签设计与批量打印工具，典型适配机型为佳博 Gprinter GP-2120TU（USB 热敏条码打印机）。** 它解决的具体问题是：把本地 Excel 清单里的每条记录，渲染成带可变文字/条码/二维码的标签，再送到本机打印机或导出为精确尺寸的 PDF。

关键设计取舍：

- **[源码确认]** 不引入任何网络库、不做更新检查、不上传数据。`src/` 下没有 HttpClient/WebClient/Socket 相关代码；文件访问统一走 `Disk.Local()` 白名单。
- **[产物确认]** REA 对 `dist/LigPrint.exe`（SHA-256 `9f01e2ea5424ba00754b46beaa7e23e19ca31928e2a2feba783d03a9dbfa3809`）的检查显示：11 个程序集引用全部是 .NET Framework 系统程序集（System.Windows.Forms / Drawing / Data / Xml / Core、mscorlib）与 3 个本地依赖（ExcelDataReader 3.7.0、ExcelNumberFormat 1.1.0、ZXing 0.16.10），**无网络相关程序集**。
- **[产物确认]** PE 头为 PE32+、machine 0x8664（x86_64）、CLI 标志 `il-only`、`strong_name_size=0`、无 ReadyToRun 签名——是一个纯托管的单文件程序。

## 二、功能模块与证据

### 1. 标签模板设计

| 能力 | 证据 | 实现要点 |
|---|---|---|
| 毫米画布、自定义尺寸 5–500 mm | [源码确认] Model.cs `LabelFile.Validate`、Studio.cs `ResizeLabel` | 保存前校验尺寸、对象数与坐标范围 |
| 七类对象 | [源码确认] Model.cs `enum Kind` | 文本 / 条形码 / 二维码 / 矩形 / 椭圆 / 横线 / 图片 |
| Code 128 + QR（UTF-8） | [源码确认] Designer.cs `Drawing.Code` | ZXing `MultiFormatWriter`，条码 margin 20、二维码 margin 4 |
| 旋转/镜像/锁定/图层/对齐 | [源码确认] Studio.cs `SetupArrange`、Designer.cs `Drawing.Paint` | 旋转在绘制期做坐标变换，设计坐标不变 |
| 多行文字与纸外排版 | [源码确认] TextBlock.cs、使用说明 | 固定 16 单位/mm 的高分辨率测量，避免换打印机后折行漂移；纸外文字被 clip 不输出 |
| 拖动、框选、缩放、多选 | [源码确认] Designer.cs `Canvas` | 鼠标消息处理、marquee 框选、Ctrl 单击增选、滚轮缩放 |
| 撤销/重做（32 步） | [源码确认] Studio.cs `History` | 每次编辑做 `LabelFile` 深拷贝快照 |
| 复制/粘贴/剪切/全选 | [源码确认] Studio.cs `ProcessCmdKey`、`CopyObjects`/`PasteObjects` | 进程内对象剪贴板，连续粘贴自动错开；属性文字框聚焦时不劫持快捷键 |

### 2. Excel 本地数据绑定

- **[源码确认]** Model.cs `ExcelBook.Read`：用 ExcelDataReader 读取 `.xls/.xlsx/.xlsb`，多工作表分别枚举；跳过全空行；首行作表头并去重；单元格按数字格式字符串经 NumberFormat 格式化，因此 `000012` 之类前导零能保留。
- **[源码确认]** 单工作簿上限 2048 列 / 400 万单元格；表头与行数列数必须一致，否则 `Validate` 拒绝。
- **[源码确认]** `Element.Value()`：对象可绑定列、固定文本或流水号（起点/步长/位数，`D` 格式化）。
- **[源码确认]** `Studio.ApplySheet()`：刷新数据时若已绑定字段在新表中缺失，拒绝加载并提示，避免静默错位。
- **[产物确认]** ExcelDataReader.dll、ExcelNumberFormat.dll 作为嵌入资源随 EXE 分发（REA 资源清单），许可文本也一并嵌入。

### 3. 批量打印预览（1.2 起的三栏界面）

- **[源码确认]** BatchPreview.cs：打印设置 / 数据库列表 / 标签预览三栏布局。
- **[源码确认]** 表头三态「全选」：`selectAll.CheckState` 依据已选记录数为 Unchecked / Checked / Indeterminate；表头点击作用于整表（含筛选隐藏行），行按钮作用于筛选结果。
- **[源码确认]** 顺序打印与自定义打印两种模式：在顺序模式下点行勾选框会先继承当前范围、切到自定义、再切换该行——这是 1.2.1 修复的勾选框失效问题的根因处理。
- **[源码确认]** 列勾选（参与本次绑定）会重建输出文档 `RefreshOutput()`，移除绑定到取消列的字段对象，并同步预览与打印。
- **[源码确认]** 每行份数 1–999，可由 Excel 列提供默认值，单行输入优先；无效份数会禁用打印按钮。
- **[源码确认]** 打印方向 0/90/180/270° 在 `LabelFile.PrintTurn` 上生效，只影响本次输出。

### 4. 打印与 PDF 导出

- **[源码确认]** Printing.cs `SubmitRows()`：`PrintDocument` 提交到所选队列；按标签毫米尺寸构造 `PaperSize`（`GetDeviceCaps` 校验驱动实际纸张，偏小则报错）；设置零边距与硬边距补偿；逐行逐份渲染并回调进度。
- **[源码确认]** PrinterQueues.cs `Installed()`：`EnumPrintersW(LOCAL|CONNECTIONS, level 4)` 枚举本机及已连接队列，用 `SortedSet` 去重；`ReadLastUsed`/`Remember` 通过 HKCU 记住上次打印机；`PreferredIndex` 优先上次成功队列，其次系统默认。
- **[源码确认]** 输出面向 Windows 标准打印队列而非品牌私有协议，因此可用机型由 Windows 驱动决定；典型示例为佳博 Gprinter GP-2120TU（USB 热敏条码打印机），铭牌所示厂商为珠海浩盛标签打印机有限公司。该示例机型未做逐台实机走纸验证。
- **[源码确认]** LabelPdf.cs `Save()`：手写 PDF 1.4，300 DPI 无损 RGB（PNG 的 IDAT 流直接用作 `/FlateDecode` + `/Predictor 15`），每条记录渲染一次图像、多份共享页资源，`MediaBox` 用 `doc.Width*72/25.4` 精确换算——因此 60×40 mm 得到 170.08×113.39 pt，而非 A4。
- **[验证记录]** `analysis/对照与验证.md` 记载：实测 PDF 页尺寸约 60.000 × 40.000 mm；用独立解码库回读 QR 与 Code 128，内容与顺序正确；1.2 版 5 页、1.2.2 版 14 页均与实际输出一致。

### 5. 文件格式与安全

- **[源码确认]** `.lig` 是 XmlSerializer 序列化的 `LabelFile`：版本、宽高、对象列表（含嵌入图片字节、绑定字段）、数据快照（表头 + 行）、源工作簿本地路径。保存用临时文件 + `File.Replace` 原子替换。
- **[源码确认]** 加载时 `XmlReaderSettings` 禁用 DTD（`DtdProcessing.Prohibit`）、`XmlResolver=null`，限制 128 MB 与 2000 对象，防止 XXE 与资源耗尽。
- **[源码确认]** `Disk.Local()` 拒绝 UNC、URL、非固定/可移动盘、以及路径链上的重解析点（符号链接/云占位）。
- **[源码确认]** `Audit.Write()` 把 UTC 时间、事件类型、数量用嵌入的 RSA-3072 公钥做 OAEP 加密后写 `%LOCALAPPDATA%\LigPrint\Logs\*.lplog`；模板内容、字段值、路径都不进日志。
- **[产物确认]** REA 资源清单含 `LigPrint.PublicKey`（585 字节）、`LigPrint.Icon`、`LigPrint.ToolbarIcon`、3 个依赖 DLL 及其 3 份许可证，共 9 项，**无私钥**。
- **[源码确认]** `Startup.ResolveLibraries()` 通过 `AssemblyResolve` 从嵌入资源加载 DLL，因此交付只需单个 EXE。

### 6. DLabel 版式迁移

- **[源码确认]** `DLabelLayout.Import()`：选择 `.ddl` 时弹出指引，让用户在 DLabel 中导出整张标签 PNG，再填写原标签宽高；`ConvertPng()` 把 PNG 作为锁定位置的整页图片对象导入，限制 32 MB / 4000 万像素，并在宽高比偏差 >2.5% 时警告。
- **[验证记录]** `analysis/对照与验证.md` 记载：对照软件 DLabel 的静态分析（REA CLI `inspect-pe-resources`，Qt 原生 x86 PE32，SHA-256 `149ecf...fb1e`）定位了 Excel 解析、可变打印、画布对象、Qt 工具栏资源等行为；LigPrint 用独立代码实现，**发行物不含 DLabel 二进制**。
- **[推断/未验证]** 未提供真实 `.ddl` 样本，因此未实现原生 `.ddl` 内部对象解析；可变字段需在导入的底图上重建。

## 五、结论

LigPrint 是一个功能完整、边界清晰的单机标签工具：从模板设计、Excel 数据绑定、批量勾选到打印/PDF 输出形成了闭环。其最鲜明的两个特点是**完全离线**与**精确尺寸 PDF 自有实现**；运行日志加密且私钥分离，兼顾了可维护性与数据最小化。REA 对发行 EXE 的静态核验与源码结论一致：单文件、无外部 DLL、无网络依赖。

需要在发布说明中如实告知使用者的限制：仅 Windows x64；实体标签机走纸与各机型驱动适配需现场确认；DLabel 模板为版式转换而非原生解析。
