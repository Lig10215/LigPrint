# LigPrint — 兼容佳博 GP-2120TU 的离线标签批量打印工具

**一款完全离线的 Windows 标签设计打印工具，典型适配佳博 Gprinter GP-2120TU（USB 热敏条码标签打印机）。** 设计标签模板、导入本地 Excel 批量生成可变数据标签、直接送到本机打印机或导出 PDF——全程不联网、不上传、不依赖云账号。

> 当前版本：**1.3.0** · 目标平台：Windows 10 / 11 x64 · 运行时：.NET Framework 4.6.2+ · 单文件便携版约 1 MB  
> 示例机型：**Gprinter 佳博 GP-2120TU**，铭牌标注「热敏条码打印机 / USB / 100–240 V~ 50/60 Hz 1.0 A」。

---

## 为什么会有这个项目

标签打印是个很具体的痛点：手头有一台标签机、一份 Excel 清单，想给每条记录打一张带条码的标签。现成工具要么要装一整套套件、要么把数据往云端传、要么模板格式私有且绑定厂商软件。

LigPrint 的目标是把这件事收敛成两个本地文件和一条明确的工作流：

1. 用可视化画布设计一个 `.lig` 标签模板（文字、Code 128 条码、二维码、图形、图片）；
2. 导入本机 Excel，把字段绑定到模板对象；
3. 在批量预览里勾选要打印的记录和每条的份数；
4. 一键送到本机 Windows 打印队列，或直接导出精确的标签尺寸 PDF。

**没有账号，没有网络请求，没有遥测。** 你的模板、Excel 数据和打印内容始终留在这台机器上。

## 兼容的标签打印机

**典型机型：佳博 Gprinter GP-2120TU。** 从机身铭牌可读出：热敏条码打印机、USB 接口、100–240 V~ 50/60 Hz 1.0 A，厂商为珠海浩盛标签打印机有限公司。安装该机型的 Windows 驱动后，打印队列会出现在本机「设备和打印机」中，LigPrint 即可通过标准 Windows 打印 API 向其输出标签。

更准确地说，LigPrint 不是为单一品牌写死的驱动，而是面向**所有能被 Windows 正常识别、且驱动接受标签尺寸纸张设置的打印机**：

- 图中示例：佳博 Gprinter GP-2120TU（USB 热敏条码打印机）；
- 同样支持其他品牌的 USB、厂商端口、TCP/IP、WSD、共享打印机与虚拟打印队列；
- 打印流程只依赖 Windows 打印队列，不调用厂商私有 SDK，也不需要云账号；
- 没有实体打印机时，可用内置 PDF 导出生成精确纸张尺寸的标签文件。

> 实体走纸、热敏打印质量与具体驱动适配未在所有机型上逐一验证。首次使用新打印机或新标签纸时，请先打一张，核对尺寸、走纸位置和扫码结果。

## 功能一览

### 标签设计器
- 毫米为单位的精确画布，默认 60 × 40 mm，可自定义 5–500 mm 任意尺寸，带刻度标尺与缩放
- 七类对象：**文本、Code 128 条形码、二维码（UTF-8）、矩形、椭圆、横线、图片**
- 对象属性面板：位置、尺寸、字体、字号、粗体、旋转 0/90/180/270°、水平镜像、位置锁定
- 对齐（靠左/居中/靠右/靠上/垂直居中/靠下）、图层次序、旋转、镜像、锁定
- 多行文本框：双击进入编辑，支持中文、换行与空行；拖动右下角按当前字号逐行折行，可放到纸外暂存而不输出
- 画布框选、Ctrl 单击多选、Ctrl+A 全选；拖动整组保持相对间距

### Excel 数据绑定
- 读取本地 `.xls` / `.xlsx` / `.xlsb`，自动识别多工作表并逐个预览（前 100 行）
- 第一行非空数据作为字段名，重复列名自动加后缀，空表头自动命名「列N」
- 保留单元格数字格式——例如 `000000` 的前导零、`00042` 这样的显示值不会被吞掉
- 任何文本、条码、二维码对象都可绑定到列，或切换为**流水号**（起点 / 步长 / 位数）
- 模板内保存数据快照和源工作簿路径；拷到另一台机器仍可用，需要更新时点「刷新数据」

### 批量打印预览（三栏）
- **左栏 · 打印设置**：打印机、打印方向（0/90/180/270°）、顺序打印或自定义打印、记录范围、默认份数、从 Excel 列读取份数
- **左栏 · 列选择**：按列名搜索，勾选「参与本次绑定的列」，可全选/反选；取消勾选的列不进入本次输出
- **中栏 · 数据库列表**：跨列关键字搜索、逐行勾选/反选、表头三态「全选」、每行份数（1–999）
- **右栏 · 实时预览**：当前记录的标签缩略图、标签信息、总张数统计
- 表头「全选」控制整张表（含搜索隐藏行），「全选结果/反选结果/清除结果」只作用于当前筛选结果
- 同一记录的各份连续排列，输出顺序与源表一致

### 打印与导出
- 枚举本机全部 Windows 打印队列：USB、厂商端口、TCP/IP、WSD、共享打印机、虚拟打印机
- 首次优先选系统默认打印机，之后记住上次成功使用的队列
- 自动按标签毫米尺寸设置纸张；驱动纸张小于标签时明确报错，避免静默错位
- **内置 PDF 导出**：自己写 PDF 1.4，每张标签一页，300 DPI 无损 RGB 图像，MediaBox 精确等于标签尺寸（例如 60 × 40 mm → 170.08 × 113.39 pt）
- 后台线程输出，可取消；条码/二维码内容在提交前逐条校验，出错明确指出是哪条记录

### 离线与隐私
- 全本地处理：**不联网、不外发、无云同步、无更新检查**
- 自研本地文件对话框只列本机固定盘与可移动盘，拒绝 URL、UNC 路径、符号链接与云占位文件
- XML 模板加载禁用 DTD、禁用外部解析器，限制文档大小（128 MB）与对象数（2000）
- 运行日志仅记录 UTC 时间、事件类型与数量，**RSA-3072 OAEP 加密**后落盘；模板内容、字段值与文件路径都不写日志
- 解密私钥（`tools/maintenance-private.xml`）**不在发行物中**，普通用户拿到 EXE 也无法解密日志；维护时用独立的 `Decode-Log.ps1`

## ⚠️ 开源前必读：不要提交私钥

本目录中的以下文件**不得上传公开仓库**：

- `tools/maintenance-private.xml` —— 日志解密私钥。一旦公开，任何人都能解密你分发出去的 `.lplog` 运行日志。已通过 `.gitignore` 排除；如需解码日志，请维护者各自保管一份，且**不要**放进仓库。
- `feedback/` —— 历次问题反馈截图，可能包含真实的样品名、批号和标签数据。已排除，建议完全不发布。
- `dist/*.exe` —— 二进制产物已排除；建议通过 GitHub Releases 单独上传，便于用户获取稳定版本与校验值。

程序本身只嵌入 **RSA 公钥**（`src/public.xml`），因此普通用户无法解密日志——这是有意的设计，请保持。

## 下载与安装

发行目录 `dist` 只有两个文件：

| 文件 | 说明 |
|---|---|
| `LigPrint.exe` | 便携版，双击即用，无需安装 |
| `LigPrint-Setup-x64.exe` | x64 安装包，按当前用户安装，带开始菜单入口与卸载 |

安装包会检测 .NET Framework 4.6.2+（缺失时提示离线安装），并为当前用户注册 `.lig` 文件关联。要求全程断网的环境请用便携版或 USB 队列；选择网络打印机时，Windows 驱动会把作业送往设备或打印服务器。

## 五分钟上手

1. 打开程序 → **新建** → 输入标签宽高（毫米）
2. 左侧点 **文本** 添加文字；选中后在右侧改内容、字体和位置；拖到想要的地方
3. 点 **插入条形码** 或 **二维码**，在右侧「数据来源」选择要绑定的 Excel 列
4. 点 **导入 Excel** → 选择工作表 → 确认预览
5. 点 **保存**，得到 `.lig` 模板（含对象、绑定和数据快照）
6. 点 **打印** → 在批量预览里选记录、设份数、核对右侧预览 → 点「打印（N 张）」

详细操作见 [`使用说明.md`](使用说明.md)，包含 `.lig` 双击打开、纸外排版、DLabel 模板转换、日志维护等完整说明。

## 从源码构建

需要：**64 位 Windows** + 系统自带的 .NET Framework C# 编译器（`csc.exe`）+ 支持 `SetupArchitecture=x64` 的 Inno Setup。

```powershell
.\build.ps1 -Iscc 'C:\工具\Inno Setup\ISCC.exe'
```

脚本会把三个 vendor DLL、公钥、图标和许可证作为嵌入式资源编译进单个 `LigPrint.exe`，再用 Inno Setup 生成安装包。**保留现有公钥即可让新旧版本的日志保持同一套密钥。** 第三方许可文本见 `vendor/*LICENSE.txt`。

验证：

```powershell
.\tools\Verify.ps1
```

它会跑回归测试与桌面控件测试（Excel 字段绑定、多工作表、前导零、批量份数、PDF 页尺寸与条码回读、队列枚举、日志解码、安装卸载等）。

## 已知限制与诚实的说明

- **仅支持 Windows x64**（依赖 Win32 打印 API、WinForms 与 .NET Framework）。
- 实体标签机走纸、热敏打印质量、特定驱动适配未在所有机型上验证；首次使用请先打一张核对位置与扫码结果。
- `.ddl` 模板不是原生解析：通过 DLabel 导出 PNG、LigPrint 按毫米导入为锁定底图，再重建可变字段。原 DLabel 对象、流水号规则和绑定需要在新模板里重建。
- 若驱动退回到更大纸张（如 A4），标签按原毫米尺寸在页面左上输出——请在打印机首选项里设置正确纸张。
- 运行日志的加密私钥需单独保管；丢失后已有日志无法解密（这是设计使然）。
